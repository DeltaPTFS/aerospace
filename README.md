# Aerospace — AeroScope ONE\n\nMobile-first aircraft map proof of concept. Public map from OpenFreeMap and MapLibre; nearby aircraft via airplanes.live point API. Data is incomplete and third-party access is subject to provider limits and terms. ATC and window experiences are simulated.\n\nTo deploy on Vercel, import this GitHub repository and select Other framework. No paid hosting is required for personal prototyping under applicable plan rules. Commercial use needs a suitable plan and data rights.\n
